Hastane Otomasyon Sistemi
Projenin Çalıştırılması:

1: Proje Visual Studio ortamında geliştirilmiştir.

2: Proje klasörü açıldıktan sonra HastaneOtomasyonu.sln dosyası Visual Studio ile açılır.

3: Veritabanı için SQL Server kullanılmaktadır.

4:Proje ile birlikte verilen .sql dosyası çalıştırılarak veritabanı oluşturulur.

5: Tablolar, Stored Procedure, Trigger, Function ve View nesneleri otomatik olarak eklenir.

6: Visual Studio içerisinde App.config açılır.

7: SQL Server bağlantı bilgileri (Server adı, Database adı) kendi bilgisayarıma göre düzenledim.

8: Start (F5) ile çalıştırılır.

Giriş Bilgileri:

-Sisteme hasta, doktor, sekreter, laboratuvar ve admin kullanıcıları giriş yapabilir.

-Kullanıcı bilgileri veritabanındaki Kullanicilar tablosu üzerinden kontrol edilmektedir.

Not:

Proje masaüstü hastane otomasyonu olarak tasarlanmıştır.

Veritabanı bağlantısı doğru yapılmadan proje çalışmayacaktır.

Tüm işlemler SQL Server üzerinden gerçekleştirilmektedir.
